1. Time-Mixing

Aplica MLPs compartidos sobre el eje temporal de forma univariante para cada canal individualmente, extrayendo dinámicas de frecuencia sin mezclar variables.

2. Feature-Mixing

Aplica capas densas cruzando las variables en cada paso de tiempo, descubriendo dependencias interactivas complejas entre las diferentes series del sistema.

3. Proyección Temporal

Mapea directamente la longitud histórica L al horizonte de predicción H de forma lineal y ultra rápida.

4. Auto-Atención + FFN

Pondera selectivamente momentos clave del pasado con atención multi-cabezal, enriqueciendo la proyección antes de emitir el pronóstico multivariante final.

Batch: Lote de muestras T (o L): Pasos de tiempo pasados C: Número de variables / canales H: Pasos predichos al horizonte
